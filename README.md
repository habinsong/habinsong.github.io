# Habin Song Photographs

내 사진(디지털/필름)과 글을 보여주는 개인 사이트입니다.

## 관리자에서 글 작성하기

1. 저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/admin/`을 엽니다.
2. 제목과 요약을 입력한 뒤 본문 편집기에 글을 씁니다.
   - 텍스트를 드래그해 선택하고 `문단`, `소제목`, `인용`을 누르면 선택한 부분의 모양이 바뀝니다.
   - 선택하지 않고 같은 버튼을 누르면 현재 위치 뒤에 새 블록이 추가됩니다.
   - 선택한 글에 `굵게`, `기울임`, `밑줄`, `작게`, `보통`, `크게`를 적용할 수 있습니다.
   - 편집 도구는 한 줄입니다. 좁은 화면에서는 도구 줄을 좌우로 밀어 사용합니다.
3. `사진 선택`으로 여러 장을 한 번에 가져오거나 사진을 가져오기 영역에 놓습니다.
   - 사진 카드에서 `첨부 완료`, `본문 미삽입` 또는 사용 위치, `설명 완료` 여부를 확인합니다.
   - 사진 한 장은 카드의 `본문에 삽입`, 여러 장은 편집기의 `사진 전체` 또는 `갤러리`로 배치합니다.
   - `정보 편집`에서 제목과 대체 텍스트를 먼저 확인하고, 촬영 정보는 필요할 때 펼칩니다.
4. 넓은 화면에서는 편집기 오른쪽의 자동 미리보기로 원고와 결과를 비교합니다. 태블릿과 휴대폰에서는 `전체 화면 미리보기`를 사용합니다.
5. `게시 설정`에서 날짜, 공개 상태, 시리즈, 태그, 사운드트랙을 확인합니다.

초안과 가져온 사진은 현재 브라우저에 자동 저장됩니다. `초안 초기화`는 이 브라우저에 저장된 글과 사진을 지우므로 게시가 끝난 뒤에만 사용하세요.

## 게시하기

1. 관리자 하단에서 `ZIP 다운로드`를 누릅니다.
2. ZIP의 내용물을 이 저장소 루트에 풉니다.
3. 다음 명령으로 병합, 데이터 검증, 정적 페이지 생성을 한 번에 실행합니다.

```bash
python3 scripts/release.py
```

4. 마지막 줄의 `release-ok:`를 확인하고 `_release/`에서 결과를 점검합니다.
5. `git status --short`로 글, 사진, 색인 파일만 바뀌었는지 확인한 뒤 커밋하고 `master`에 푸시합니다. GitHub Actions가 `_release/`를 다시 만들고 Pages에 배포합니다.

같은 글 ID로 다시 게시하면 기존 글과 색인 항목이 갱신됩니다. 사용하지 않은 사진은 게시 전에 관리자 사진 카드에서 삭제하세요.
