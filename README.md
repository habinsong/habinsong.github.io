# Habin Song Photographs

내 사진(디지털/필름)과 글을 보여주는 개인 사이트입니다.

---

## 글 한 편 올리는 순서

```
로컬 서버 켜기 → localhost:8000/admin/ 에서 쓰기 → ZIP 내려받기
→ ZIP을 이 폴더에 풀기 → python3 scripts/release.py → git push
```

푸시하고 1~2분이면 사이트에 반영됩니다.

---

## 1. 준비물

- **Python 3** — macOS에 기본으로 있습니다. `python3 --version` 으로 확인
- **git**
- 브라우저 (Chrome, Safari, Edge, Firefox 최신 버전)

## 2. 로컬에서 열기

파일을 더블클릭하면 안 됩니다. 브라우저 보안 때문에 빈 화면이 나옵니다. 터미널에서:

```bash
cd ~/habinsong
python3 -m http.server 8000
```

- 사이트 미리보기: <http://localhost:8000>
- 글쓰기: <http://localhost:8000/admin/>

끌 때는 그 터미널에서 `Ctrl+C`.

## 3. 글 쓰기

<http://localhost:8000/admin/> 에서 씁니다. 왼쪽이 작성, 오른쪽이 미리보기입니다.

### 3-1. 글 정보

| 항목 | 설명 |
|------|------|
| 제목 | 파일 이름도 제목에서 자동으로 만들어집니다. 한글 됩니다 |
| 날짜 | 목록과 아카이브 정렬에 쓰입니다 |
| 상태 | **게시** = 사이트에 보임, **초안** = 안 보임 |
| 시리즈 | 선택. 같은 이름을 쓴 글끼리 묶입니다 (예: `제주 2026`) |
| 태그 | 쉼표로 구분 (예: `film, seoul`) |
| 요약 | 글 목록에 한두 문장으로 보입니다 |

### 3-2. 사진 넣기

**사진** 영역에 이미지를 끌어다 놓거나 파일 선택을 누릅니다.

- 카메라·렌즈·조리개·셔터·ISO와 연도는 EXIF에서 자동으로 채워집니다. 필름 스캔처럼 EXIF가 없으면 직접 쓰면 됩니다
- 가로세로 비율은 실제 픽셀에서 자동으로 잡힙니다
- **대체 텍스트(alt)** 는 채우세요. 화면을 못 보는 사람과 검색엔진이 읽는 설명입니다
- **매체**(디지털/필름)와 **톤**(컬러/흑백)은 갤러리 필터에 쓰입니다
- **본문에 삽입** 을 누르면 커서 자리에 들어갑니다

올린 사진은 브라우저에 저장되므로 새로고침해도 안 사라집니다.

### 3-3. 본문 쓰기

캔버스를 클릭하고 그냥 쓰면 됩니다.

- `Enter` — 새 문단
- 툴바 **본문 / 소제목 / 인용** — 커서가 있는 문단의 모양 바꾸기
- 툴바 **사진** — 커서 자리에 사진 넣기. 캔버스에 파일을 바로 끌어다 놔도 됩니다
- 사진 아래 **코멘트** — 그 사진에 붙는 짧은 글
- **사진 전체 추가** — 올린 사진을 한 번에 본문으로
- **갤러리** — 여러 장을 격자 하나로 묶기. 체크박스로 고릅니다
- **링크** — 한 줄에 하나, `이름 | https://주소` 형식
- 블록의 **↑ ↓ ×** — 순서 이동과 삭제

붙여넣기하면 서식은 버리고 글자만 들어옵니다. 그렇게 만들어 뒀습니다.

쓰는 동안 자동 저장됩니다. 오른쪽 위에 저장된 시각이 보입니다. 같은 브라우저에서 다시 열면 이어서 쓸 수 있습니다.

## 4. 올리기

1. 관리자 화면 아래 **ZIP 내려받기** 를 누릅니다. 빠진 항목이 있으면 알려 줍니다
2. 내려받은 ZIP을 **이 폴더에 풉니다**. 글과 사진이 제자리로 들어갑니다
3. 터미널에서:

```bash
cd ~/habinsong
python3 scripts/release.py
git add -A
git commit -m "새 글: 제목"
git push
```

`release.py`가 빠진 사진이나 잘못된 값을 먼저 잡아 줍니다. 문제가 있으면 어디가 잘못됐는지 알려 주고 멈추므로, 깨진 채로 올라가지 않습니다.

## 5. 올린 글 고치기

1. 관리자에서 **JSON 불러오기** → `content/posts/` 에서 그 글 파일 선택
2. 고칩니다. 사진은 이미 저장소에 있으므로 원본 파일이 없어도 됩니다
3. 다시 **ZIP 내려받기** 하고 4번 그대로. 같은 글이 갱신됩니다

## 6. 글 내리기

`content/posts/index.json` 에서 그 글의 `"status"` 를 `"published"` 에서 `"draft"` 로 바꾸고, 4번의 터미널 명령을 실행합니다. 다시 올리려면 반대로 바꾸면 됩니다.

## 7. 시리즈

같은 시리즈 이름으로 쓴 글은 사이트의 **시리즈** 에 묶여 나옵니다. 설명을 붙이려면 `series.json` 의 해당 항목에 `description` 을 넣습니다.

```json
{ "id": "제주-2026", "title": "제주 2026", "description": "한 주 동안의 제주." }
```

## 8. 언어

사이트 화면은 한국어·영어·일본어·중국어로 나옵니다. 방문자의 브라우저 언어로 자동으로 정해지고, 맨 위에서 바꿀 수 있으며 그 선택은 기억됩니다. **글 본문은 쓴 언어 그대로** 나옵니다. 번역되는 것은 메뉴 같은 화면 문구뿐입니다.

## 9. 새 컴퓨터에서 시작할 때

```bash
git clone https://github.com/habinsong/habinsong.github.io.git ~/habinsong
cd ~/habinsong
python3 -m http.server 8000
```

## 10. 안 될 때

| 증상 | 해결 |
|------|------|
| 고쳤는데 화면이 그대로 | 브라우저 캐시입니다. `Cmd+Shift+R` |
| 관리자 화면이 하얗게 나옴 | 파일을 더블클릭으로 열었을 겁니다. 2번처럼 로컬 서버로 여세요 |
| `release-error:` 로 시작하는 빨간 글 | 메시지가 가리키는 것을 고치면 됩니다. 사진 파일 누락이나 빈 alt가 대부분입니다 |
| 다른 브라우저에 쓰던 초안이 없음 | 초안과 사진은 브라우저마다 따로 저장됩니다. 쓰던 브라우저에서 이어 쓰세요 |
| 사진을 잘못 올림 | 사진 패널의 **삭제**. 본문에 넣은 것도 같이 빠집니다 |
| 처음부터 다시 쓰고 싶음 | **초안 초기화**. 저장된 사진까지 전부 지워집니다 |
| 푸시했는데 사이트가 그대로 | 저장소의 **Actions** 탭에서 방금 실행이 성공했는지 봅니다 |
