# Habin Song Photographs

내 사진(디지털/필름)과 글을 보여주는 개인 사이트입니다.

---

## 이게 어떻게 돌아가는가

서버가 없습니다. 그래서 글을 쓰면 바로 인터넷에 올라가지 않고, 이런 순서를 거칩니다.

1. 내 컴퓨터에서 **관리자 화면**을 열어 글을 씁니다
2. 다 쓰면 **ZIP 파일 하나**를 내려받습니다. 그 안에 글과 사진이 들어 있습니다
3. 그 ZIP을 이 폴더에 풀고, 터미널에 **명령 세 줄**을 칩니다
4. 1~2분 뒤 사이트에 올라갑니다

아래에 하나씩 다 씁니다.

---

## 1. 시작하기 (글 쓸 때마다 하는 것)

**터미널**을 엽니다. `Cmd + Space` 를 누르고 `터미널` 또는 `terminal` 이라고 치면 나옵니다.

터미널에 아래를 그대로 치고 `Enter`:

```bash
cd ~/habinsong
python3 -m http.server 8000
```

`Serving HTTP on ...` 같은 글이 나오면 켜진 겁니다. **이 터미널 창은 끄지 마세요.** 글 쓰는 동안 계속 켜져 있어야 합니다.

이제 브라우저에서 주소 두 개를 씁니다.

| 주소 | 용도 |
|------|------|
| <http://localhost:8000> | 내 사이트가 어떻게 보이는지 미리보기 |
| <http://localhost:8000/admin/> | **글 쓰는 곳** |

다 쓰고 나면 터미널로 돌아가 `Ctrl + C` 를 눌러 끕니다.

> 파일을 더블클릭해서 열면 안 됩니다. 화면이 하얗게 나옵니다. 반드시 위 주소로 여세요.

---

## 2. 글 쓰기

<http://localhost:8000/admin/> 를 엽니다. 화면 왼쪽이 쓰는 곳, 오른쪽이 **미리보기**입니다. 왼쪽에 뭘 넣으면 오른쪽이 바로 바뀝니다.

화면을 위에서부터 순서대로 채우면 됩니다.

### 2-1. 글 정보

| 칸 | 뭘 넣나 | 예시 |
|----|---------|------|
| **제목** | 글 제목. 한글 됩니다 | `종로에서 찍은 한 롤` |
| **날짜** | 달력에서 고릅니다. 목록 정렬에 쓰입니다 | `2026-08-01` |
| **상태** | **게시** = 사이트에 보임 / **초안** = 안 보임 | 게시 |
| **시리즈 (선택)** | 연작 이름. 안 써도 됩니다 | `제주 2026` |
| **태그** | 쉼표로 구분 | `film, seoul` |
| **요약** | 글 목록에 한두 줄로 보이는 소개 | `여름 오후의 종로. 포트라 400.` |

**제목**과 **요약**은 비워두면 ZIP을 못 받습니다. 나머지는 선택입니다.

같은 시리즈 이름을 다른 글에도 쓰면 사이트의 **시리즈** 칸에 묶여서 나옵니다.

### 2-2. 사진 올리기

**사진** 이라고 적힌 칸에 이미지 파일을 **끌어다 놓거나**, 파일 선택 버튼을 눌러 고릅니다. 여러 장 한 번에 됩니다.

사진을 넣으면 그 사진마다 아래 칸들이 생깁니다.

| 칸 | 설명 |
|----|------|
| **대체 텍스트** | 사진 설명. **반드시 채워야 합니다.** 비어 있으면 ZIP을 못 받습니다. 눈이 불편한 사람이 듣는 문장이고 검색엔진이 읽는 문장입니다. 예: `종로 골목의 낡은 간판` |
| **매체** | 디지털 / 필름. 갤러리 필터에 쓰입니다 |
| **톤** | 컬러 / 흑백. 갤러리 필터에 쓰입니다 |
| **장소** | 예: `서울 종로` |
| **연도** | 사진에 EXIF가 있으면 자동으로 채워집니다 |
| **비율(가로) · 비율(세로)** | 자동으로 채워집니다. 건드릴 일 없습니다 |
| **세부 정보** | 카메라·렌즈·조리개·셔터·ISO. EXIF가 있으면 자동으로 채워집니다. 필름 스캔처럼 EXIF가 없으면 직접 씁니다 |

사진 아래 두 버튼:

- **본문에 삽입** — 지금 커서가 있는 자리에 이 사진을 넣습니다
- **삭제** — 이 사진을 뺍니다. 본문에 넣었던 것도 같이 빠집니다

> 올린 사진과 쓰던 글은 브라우저에 저장됩니다. 새로고침해도, 컴퓨터를 껐다 켜도 남아 있습니다. 다만 **브라우저마다 따로** 저장됩니다. 사파리에서 쓰던 걸 크롬에서 열면 없습니다.

### 2-3. 본문 쓰기

**본문** 칸의 흰 영역을 클릭하고 그냥 쓰면 됩니다. 워드처럼요. `Enter` 를 누르면 문단이 나뉩니다.

위쪽 버튼들이 하는 일:

| 버튼 | 하는 일 |
|------|---------|
| **본문** | 커서가 있는 문단을 보통 글로 |
| **소제목** | 커서가 있는 문단을 제목 크기로 |
| **인용** | 커서가 있는 문단을 인용문 모양으로 |
| **사진** | 커서 자리에 사진 넣기. 파일을 캔버스에 바로 끌어다 놔도 됩니다 |
| **사진 전체 추가** | 위에서 올린 사진을 전부 한 번에 본문으로 |
| **갤러리** | 여러 장을 격자 하나로 묶기. 체크박스로 고릅니다 |
| **링크** | 참고 링크 목록. 한 줄에 하나씩 `이름 \| https://주소` 형식으로 |

본문에 넣은 사진 아래에는 **코멘트** 칸이 생깁니다. 그 사진에만 붙는 짧은 글입니다. 안 써도 됩니다.

사진·갤러리·링크 덩어리 옆의 **위로 · 아래로 · 삭제** 로 순서를 바꾸고 뺍니다.

다른 데서 글을 복사해 붙여넣으면 글자만 들어오고 서식은 버려집니다. 일부러 그렇게 해뒀습니다.

오른쪽 위에 **초안이 로컬에 저장됨** 이라고 뜨면 저장된 겁니다. 따로 저장 버튼은 없습니다.

## 3. 올리기

여기부터가 실제로 인터넷에 올리는 부분입니다.

### 3-1. ZIP 내려받기

화면 아래 **콘텐츠 번들 만들기** 에서 **ZIP 내려받기** 를 누릅니다.

빠진 게 있으면 빨간 글로 알려주고 안 내려받아집니다.

| 나오는 말 | 뜻 |
|-----------|-----|
| 제목을 입력하세요 | 제목 칸이 비었습니다 |
| 요약을 입력하세요 | 요약 칸이 비었습니다 |
| 콘텐츠 블록이 하나 이상 필요합니다 | 본문이 비었습니다 |
| "○○"의 대체 텍스트를 입력하세요 | 그 사진의 대체 텍스트 칸이 비었습니다 |

내려받아지면 `Downloads` 에 `글이름-content-bundle.zip` 이 생깁니다.

### 3-2. ZIP을 이 폴더에 풀기

**여기서 제일 많이 틀립니다.** ZIP 안의 것들이 `~/habinsong` 폴더 **안으로** 들어가야 합니다. ZIP을 통째로 폴더 하나로 넣으면 안 됩니다.

터미널을 **새 창으로** 하나 더 엽니다 (`Cmd + N`). 서버 켜둔 창은 그대로 두세요. 새 창에서:

```bash
unzip -o ~/Downloads/글이름-content-bundle.zip -d ~/habinsong
```

`글이름-content-bundle.zip` 자리에는 실제 파일 이름을 넣습니다. 이름 치기 귀찮으면 `unzip -o ` 까지 치고 **Finder에서 ZIP 파일을 터미널 창으로 끌어다 놓으면** 경로가 자동으로 들어갑니다. 그 뒤에 ` -d ~/habinsong` 를 붙이고 `Enter`.

### 3-3. 명령 세 줄

같은 터미널 창에서 이어서:

```bash
cd ~/habinsong
python3 scripts/release.py
git add -A && git commit -m "새 글" && git push
```

- 첫 줄 — 폴더로 이동
- 둘째 줄 — 검사. `release-ok:` 로 끝나면 통과입니다. `release-error:` 가 나오면 **아래 3-4** 를 보세요
- 셋째 줄 — 인터넷으로 보내기

`"새 글"` 자리에 글 제목을 넣어도 되고 그냥 둬도 됩니다. 기록용일 뿐입니다.

### 3-4. `release-error:` 가 나오면

올라가지 않고 멈춘 겁니다. 깨진 채로 올라갈 일은 없으니 안심하고, 메시지가 가리키는 것을 고치면 됩니다.

| 메시지 | 뜻 |
|--------|-----|
| `Missing photo asset: ...` | 사진 파일이 안 들어왔습니다. ZIP을 다시 풀어 보세요 (3-2) |
| `... requires non-empty alt` | 대체 텍스트가 빈 사진이 있습니다 |
| `Unknown series for ...` | 시리즈 이름을 새로 썼는데 목록에 없습니다. ZIP을 다시 받아 푸세요 |

고친 다음 3-3의 명령 세 줄을 다시 치면 됩니다.

### 3-5. 확인

푸시하고 1~2분 뒤 <https://habinsong.github.io/> 를 새로고침하면 올라와 있습니다.

안 보이면 `Cmd + Shift + R` 로 강력 새로고침. 그래도 없으면 GitHub 저장소의 **Actions** 탭에서 방금 실행이 초록색인지 봅니다.

## 4. 처음부터 끝까지 한 번 (예시)

종로에서 찍은 필름 한 롤을 올린다고 하면:

```bash
# 터미널 1 — 서버 켜기 (끄지 않고 둠)
cd ~/habinsong
python3 -m http.server 8000
```

1. 브라우저에서 <http://localhost:8000/admin/> 열기
2. **제목** `종로에서 찍은 한 롤` · **날짜** 오늘 · **상태** 게시
3. **태그** `film, seoul` · **요약** `여름 오후의 종로. 포트라 400.`
4. 스캔한 사진 12장을 **사진** 칸에 끌어다 놓기
5. 사진마다 **대체 텍스트** 채우기 (12장 다)
6. **매체** 는 필름, **톤** 은 컬러로
7. 본문 칸에 첫 문단 쓰기
8. **사진 전체 추가** 눌러 12장을 본문에 넣기
9. 마음에 드는 사진 아래 **코멘트** 몇 개 달기
10. 오른쪽 미리보기로 확인
11. **ZIP 내려받기**

```bash
# 터미널 2 — 올리기
unzip -o ~/Downloads/종로에서-찍은-한-롤-content-bundle.zip -d ~/habinsong
cd ~/habinsong
python3 scripts/release.py
git add -A && git commit -m "종로에서 찍은 한 롤" && git push
```

끝입니다.

## 5. 이미 올린 글 고치기

1. 관리자 화면에서 **JSON 불러오기** 를 누릅니다
2. `~/habinsong/content/posts/` 안에서 그 글의 파일을 고릅니다
3. 내용이 그대로 불려 옵니다. 고칩니다
   - 사진은 이미 저장소에 있으므로 **원본 파일을 다시 안 올려도 됩니다**
4. **ZIP 내려받기** 하고 3장 그대로 다시 합니다

같은 글로 인식해서 갱신됩니다. 새 글이 생기지 않습니다.

## 6. 올린 글 내리기

`~/habinsong/content/posts/index.json` 을 텍스트 편집기로 엽니다. 그 글 항목에서

```json
"status": "published"
```

를

```json
"status": "draft"
```

로 바꾸고 저장한 뒤, 3-3의 명령 세 줄을 칩니다. 다시 올리려면 반대로 바꿉니다.

## 7. 시리즈 설명 붙이기

`~/habinsong/series.json` 을 열어 그 시리즈에 `description` 을 넣습니다.

```json
{ "id": "제주-2026", "title": "제주 2026", "description": "한 주 동안의 제주." }
```

저장하고 3-3의 명령 세 줄.

## 8. 언어

사이트 화면은 한국어·영어·일본어·중국어로 나옵니다. 방문자의 브라우저 언어로 자동으로 정해지고, 맨 위에서 바꿀 수 있으며 그 선택은 기억됩니다.

**글 본문은 쓴 언어 그대로** 나옵니다. 번역되는 건 메뉴 같은 화면 문구뿐입니다.

## 9. 새 컴퓨터에서 시작할 때

```bash
git clone https://github.com/habinsong/habinsong.github.io.git ~/habinsong
cd ~/habinsong
python3 -m http.server 8000
```

## 10. 안 될 때

| 증상 | 해결 |
|------|------|
| 관리자 화면이 하얗게 나옴 | 파일을 더블클릭으로 열었습니다. 1장처럼 `localhost:8000/admin/` 으로 여세요 |
| `localhost:8000` 이 안 열림 | 서버 터미널이 꺼졌습니다. 1장 명령을 다시 치세요 |
| 고쳤는데 화면이 그대로 | `Cmd + Shift + R` |
| 쓰던 초안이 없어짐 | 다른 브라우저로 열었을 겁니다. 초안은 브라우저마다 따로 저장됩니다 |
| 사진을 잘못 올림 | 그 사진의 **삭제**. 본문에 넣은 것도 같이 빠집니다 |
| 처음부터 다시 쓰고 싶음 | **초안 초기화**. 올린 사진까지 전부 지워집니다. 되돌릴 수 없습니다 |
| `release-error:` | 3-4를 보세요 |
| 푸시했는데 사이트가 그대로 | 저장소 **Actions** 탭에서 마지막 실행이 초록색인지 확인 |
